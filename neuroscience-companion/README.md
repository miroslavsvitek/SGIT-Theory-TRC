# Companion computational repository — temporal circulation-like EEG relationships

This public branch holds the **manuscript companion index and exact source provenance** for the research article *Reproducible temporal organization of circulation-like EEG relationships during conscious perception* (prepared for Neuroscience, 28 Oct 2026).

## Frozen discovery/replication baseline

Original open reference repository: https://github.com/miroslavsvitek/SGIT-Hodge-Curl-Conscious-Visual-Detection
Frozen commit: `f0ffc52cf0003bdba2e90ca53712375beda6709d`.
Archived DOI: https://doi.org/10.5281/zenodo.22674728

The source repository includes frozen selected geometry, methods code and supplementary assets. The exact S7 numerical geometry has 64 nodes, 222 edges, 216 triangles, 12 selected CURL and 12 GRAD modes, SHA256 `ec54f49377b9a97427b46f10305e8995af5fb7d9628dbd17e7d6f915de3944b6`.

## Public input data

OpenNeuro [ds006171](https://openneuro.org/datasets/ds006171) is the referenced archived visual feature source. OpenNeuro [ds005273](https://openneuro.org/datasets/ds005273), originally analysed by Rodriguez-San Esteban et al. (Scientific Reports, 2025, DOI 10.1038/s41598-025-92490-y), is the separate October 2026 exploratory visual EEG source.

Raw EEG is not reposted here. Historic 30 + 35-subject outcomes and 27-subject saved-feature analysis are **archived previously reported outcomes**, not a new reproduction performed by this branch.

## What is independently rerunnable

1. Original source and archived geometry at the fixed commit above.
2. The local submitted companion ZIP contains the exact geometry file, source scripts and three untouched exploratory result ZIPs with config and subject-level CSVs.
3. This branch's evidence ledger lists precise status and distinguishes reproduced discoveries from later exploratory negative tests.

**Do not represent this GitHub branch alone as containing every historic participant-level trial input or as a newly registered confirmatory experiment.** The detailed local submission companion is a separate downloadable artifact until uploaded and versioned as a release.
