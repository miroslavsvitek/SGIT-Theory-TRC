# Methods and claims

`src/sgit/core.py` implements the mathematical reference construction: oriented normalized determinant, simplicial incidence/Hodge operations, 12-mode projections, window normalization, condition-centred third cross-moments, S3-sector energies, symmetry fingerprint, and trial-pair-preserving surrogates.

The symmetry readout is a **condition-contrast statistic**, not a direct single-trial classifier of consciousness. Preserved-pair surrogates test specifically defined trial-link rearrangements, not the exclusion of every possible pairwise generative model. Input preprocessing, EEG referencing, subject inclusion, experimental null calibration and third-party dataset access must be documented separately per study.
